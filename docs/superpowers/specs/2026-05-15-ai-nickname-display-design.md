# AI 昵称展示 — 设计文档

Status: Design approved
Date: 2026-05-15

## 目标

页面上 AI 机器人和聊天消息都显示可读昵称，不再把内部玩家 ID 暴露给用户。内部协议仍保留 ID 用于动作目标、投票和查验，避免破坏游戏逻辑。

## 昵称规则

AI 玩家沿用现有 `Persona` 人设名称作为角色风格昵称，例如 `理性派`、`冲锋派`、`和事佬`。同一房间内若随机到重复人设，则给后续昵称追加编号，例如 `理性派2`。

## 显示范围

- 圆桌座位使用 `player.nickname` 显示 AI 和真人昵称。
- 聊天区域显示发送者昵称，不显示 `h_xxx` 或 `ai_xxx`。
- 预言家查验记录显示目标昵称。
- 游戏结束角色列表显示昵称和角色。

## 数据流

后端仍用玩家 ID 接收和处理动作。后端广播聊天事件时，根据发送者 ID 附带发送者昵称。前端聊天组件优先显示昵称字段，并保留 ID 作为兼容兜底。

## 测试

- 后端测试覆盖 AI 昵称不是 `AI-1` 这类默认编号，并且同房间昵称唯一。
- 后端测试覆盖聊天事件携带发送者昵称。
- 前端构建验证展示代码可编译。
